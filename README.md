# Lexora (formerly Language Tracker)

A smart, lightweight web application designed to help you memorize foreign vocabulary efficiently. Lexora provides a clean, modern interface for tracking your learning progress and expanding your dictionary day by day.

## ✨ Features
- **Secure Authentication:** User registration and log in using JWT (JSON Web Tokens).
- **Personalized Vocabulary:** Add and manage your own words with translations and difficulty levels (Easy, Medium, Hard).
- **Modern UI/UX:** A "Clean SaaS" aesthetic built with native CSS variables, flexbox, and grid layouts.
- **Seamless Navigation:** Vanilla JavaScript Single Page Application (SPA) architecture for instant section switching without page reloads.
- **Smart Routing:** Automatic route guards to protect authorized content.

## 🛠 Tech Stack
**Frontend:**
- HTML5 & CSS3 (Custom Properties)
- Vanilla JavaScript (ES6+, Fetch API)

**Backend:**
- Python 3
- FastAPI
- SQLite & SQLAlchemy (ORM)
- Security: Passlib (bcrypt) & Python-JOSE (JWT)
